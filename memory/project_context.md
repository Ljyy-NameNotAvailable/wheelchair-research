The course is **edge computing**. Research framing must center on edge deployment challenges, not behavioral science or user studies.

**Why:** Early proposals were too "文科" (humanities-leaning) — user adaptation studies are not appropriate for this course context.

**How to apply:** All research questions, proposals, and literature suggestions should be grounded in edge computing concerns: latency, model compression, computation offloading, on-device inference, battery/power constraints, real-time performance on resource-constrained hardware.
